# CozyVerse Ecommerce — Componentized React + Mantine

All major UI sections are separated into `src/components`. `App.tsx` only composes the page and owns application state.

## Structure

```text
src/
├── App.tsx
├── main.tsx
├── styles.css
└── components/
    ├── Header.tsx
    ├── MobileNav.tsx
    ├── Hero.tsx
    ├── PromoCards.tsx
    ├── SectionTitle.tsx
    ├── ProductCard.tsx
    ├── ProductGrid.tsx
    ├── Recommendations.tsx
    ├── CollectionButton.tsx
    ├── FinalCTA.tsx
    ├── Footer.tsx
    ├── CartDrawer.tsx
    ├── ProductModal.tsx
    ├── data.ts
    └── index.ts
```

Run with `npm install` then `npm run dev`.


[Check it here](https://ecommerce-site-virid-psi.vercel.app/)
